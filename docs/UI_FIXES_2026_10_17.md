# Remote feedback implementation — October 17, 2026

This supersedes conflicting October 11/original five-screen interactions.
All sixteen changes use the shared UI/controller/offline model. Physical
touch feel still requires retesting.

| Feedback | Change |
| --- | --- |
| 1. Repeated taps / slow simulation | Ordinary buttons accept slow clicks; hold actions fire once. Decorations/roots cannot scroll or steal clicks. Board release retains last coordinates. Mock confirmation 40 ms, telemetry 100 ms, pending hint after 250 ms. Explicit edits preserve pending settings without inventing confirmation. |
| 2. Overlapping scale values | Retain exact max; suppress nearby intermediate labels using angular spacing and bounds. KG landmarks use displayed units. |
| 3. Matching presets | Compare confirmed effective recipes after unit conversion. Ignore dormant values; retain selected/saved duplicate slots. |
| 4. Preset circle / P10 | Four circles fit the round face; centered 18 px preset text has room for P99. |
| 5. RP values | Icons above circles; values use whole circle. All three lines centered; small-screen font increased from 12 to 14 px. |
| 6. Sets/reps/rest | Larger 18 px text from fresh valid reports only. No UI workout timer/counters. Mock load/unload without a rep no longer creates an empty completed set/rest timer. |
| 7. Magic/EO Back | Removed; central amount applies/returns. Unload status target retained. |
| 8. Dial speed | One tick slowly; 5 ticks below 130 ms, 10 below 55 ms. Reversal/navigation reset acceleration. |
| 9. Save preset | Return to Main; saved slot selected when confirmed. If settings changed during Save, explicitly request saved recipe. Never load. |
| 10. Name hit area | Separate tall header above weight hit area, in front of number container. |
| 11. KG fractions | 0.5 KG ticks in formatting, conversion, limits and persistence; LB stays integer. |
| 12. Device picker | Arrows/swipe/rotary paging. No availability badges or help caption. Bright/dim availability, overlapping Twin circles. |
| 13. Twin limit | Report first, firmware fallback second. 2.x = 460 LB / nominal 208 KG. See WEIGHT_LIMITS.md. |
| 14. Swipe/tap | Movement cancels click/hold. Release position counts even without intermediate samples. Swipe changes one page. |
| 15. Zero modifiers | Trim EO then Magic; disable at zero. Editors/controller/mock reject enabled zero. No headroom shows OFF. |
| 16. Mode gestures | Off tap opens editor; active tap disables; hold edits either state. |

Explicit unload also fixes editor cancel during pending load: it always requests
unload. LOAD still requires a current action, fresh state/readiness, and is not
queued behind pending conflicting requests.
