# VOLTRA Remote v0.4.26 — Twin recovery and Live

- Return to the main device screen when an idle VOLTRA disconnects. A
  connection lost during a live set still shows a notice.
- Connect through the verified Twin controller even when only one unit is
  advertising. Limit attempts for an unavailable Twin member to two.
- Return to weight controls on a reported Twin rest or a sustained period of
  fresh idle telemetry. The weight stays loaded until the VOLTRA unloads.
- Keep paired pull and return samples and their workout context in an
  explicitly sent BLE trace.

The exact combined Twin Live weight remains under investigation.

Unload the VOLTRAs and leave the connection. In **Settings → Updates**,
choose **Check for updates**, then **Install & Restart**. Keep power connected.
