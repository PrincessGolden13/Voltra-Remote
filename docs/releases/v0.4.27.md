# VOLTRA Remote v0.4.27 — Updates and standalone Live

- Open **Settings → Updates** to check automatically. Install remains an
  explicit action when a newer version is available.
- Recover the device-reported standalone Live target during a loaded session
  when the VOLTRA supplies it by readback instead of the B4 stream.
- Keep the Stairs return candidate when a transition packet still carries
  the preceding rep count. The reduction waits for a confirmed stationary
  endpoint.
- On a verified single VOLTRA, offer confirmation for eligible Direct Load
  with the cable extended. Show an inline explanation if current settings
  prevent the remote from starting the guided load.

Unload the VOLTRAs and leave the connection. On v0.4.26, open
**Settings → Updates**, tap **Check for updates**, then **Install & Restart**.
Keep power connected.
