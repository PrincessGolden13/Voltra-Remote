First public source and firmware release for the Guition JC3636K518 remote.

- Firmware checks GitHub at startup over saved Wi-Fi and prompts before installing.
- Settings -> Updates checks the same release feed and downloads on request.
- Normal A/B update slots preserve the separate offline Simulator.
- HTTPS, SHA-256, board/channel/version checks and startup rollback protection.
- MIT source, build workflow, USB installer and contributor documentation.

**Initial USB installation required:** older partition layouts cannot install this
release wirelessly. Use the USB ZIP, which includes an installer that verifies a
full recovery backup before writing. Never flash the OTA-only image at address zero.

**Development release:** this is not plug-and-play for every remote. Fresh BLE
bootstrap identities have not established pairing in our physical trials. The
owner's working local profile can be retained in device NVS by a local migration
build; it is not included in public binaries. Source publication does not establish
physical compatibility. See docs/LIVE_CONNECTION_2026_10_18.md and docs/SAFETY.md.

OTA transfer, power-cut recovery and startup rollback still need physical
verification. No automated test engages a motor. Do not install while training.

Assets: `voltra-remote-guition-k5.bin` is the Normal OTA image; `guition-k5.json`
is its update manifest; `voltra-remote-guition-k5-usb.zip` is the initial installer;
`voltra-remote-guition-k5-relink.zip` contains compiled objects/ELFs for relinking.
