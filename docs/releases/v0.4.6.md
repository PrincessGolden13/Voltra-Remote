# VOLTRA Remote v0.4.6

- Preserve saved Wi-Fi and remote settings through normal firmware updates.
  Refuse automatic whole-settings erases from storage-error recovery, and prevent
  failed or incompatible settings reads from being saved back as defaults.
- Verify saved preferences and Wi-Fi credentials before installing an update.
  A failed verification blocks installation instead of restarting with an
  unverified save. Settings and flash layout remain compatible with earlier images.
- After successful Wi-Fi setup, show the saved connection and only OK, returning
  to Settings. Opening Wi-Fi with a saved network no longer starts setup again.
  Cancelling setup keeps the previously saved network.
- Opening an already configured Wi-Fi screen shows the connected/saved network,
  checks reachability with an ICMP ping to Google DNS 8.8.8.8, and offers RESET
  WI-FI to configure a replacement. A ping reply confirms Internet reachability;
  no reply is shown as unconfirmed, separately from Wi-Fi association.

The exact cause of the reported prior loss is not confirmed. Already-erased data
cannot be recovered by this update, and storage-fault/rollback recovery is not
guaranteed. No resistance-control protocol or load guard changes are included.

For Guition K5 with the existing v0.4.1+ flash layout. Unload, leave Bluetooth,
then Settings -> Updates -> CHECK FOR UPDATES -> INSTALL & RESTART. Keep power
connected. Physical Wi-Fi success/OK, ping/reset behavior and settings retention across OTA
still need the owner's check. Validation evidence is in docs/TESTING.md.

Build and artifact validation, with exact source revisions, is recorded in
docs/TESTING.md. No physical network or motor tests are claimed.
