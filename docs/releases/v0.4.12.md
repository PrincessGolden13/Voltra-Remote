# VOLTRA Remote v0.4.12 — Retry connection timeouts

Report58926a2a exposed a Bluetooth timeout that the remote did not retry. It then
connected to the follower and replaced the original timeout with an unhelpful
“Could not identify the paired controller” message.

- Give a timed-out Bluetooth connection one retry, using shorter attempts within
  the existing ten-second radio budget. Retain the existing one-second MTU grace;
  retries do not extend the overall connection window.
- Preserve the actual timeout when the other VOLTRA identifies itself as the
  follower. Retry remains available and starts with the updated master candidate.
- Keep connection diagnostics concise enough to retain failure details without
  repeating the same closed-session snapshot.

The report confirms v0.4.11 recognizes this follower correctly. It does not reveal
why the first radio connection received no response, or prove another app is
connected. Physical improvement from the retry policy still needs verification.

**Twin weight adjustment, load, unload and Auto Load remain unavailable on the
remote. Use the VOLTRAs' own controls.** Twin screens remain read-only.
Saved Wi-Fi and other settings are preserved.

Unload both VOLTRAs and leave the connection, then Settings -> Updates -> CHECK
FOR UPDATES -> INSTALL & RESTART. Keep power connected.
