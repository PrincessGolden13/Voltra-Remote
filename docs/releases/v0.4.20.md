# VOLTRA Remote v0.4.20

- Devices checks Twin status earlier and revisits a confirmed single during
  discovery, so an already-open Devices screen can update its Twin icon.
- A Bluetooth connection failure tells you to disconnect phones and other
  Bluetooth controllers from the VOLTRAs before retrying.
- If you tap a visible follower, the remote can spend longer connecting to
  the exact controller it reports. Cancel returns to Devices. The remote
  checks the roles and pair again before allowing controls.
- The Send debug log screen uses shorter instructions and keeps the unload
  control and report receipt.
- If an established connection ends, the notice shows a known VOLTRA
  exit or a short disconnect message. It offers Back and Retry where
  available. Manual reports remain available from Settings.

The longer Bluetooth attempt is a way to recover a controller that is temporarily
hard to reach. Physical behavior after this update is unverified.

Unload the VOLTRAs and leave the connection. In **Settings → Updates** select
**Check for updates**, then **Install & Restart**. Keep power connected.
