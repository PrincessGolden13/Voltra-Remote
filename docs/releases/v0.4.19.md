# VOLTRA Remote v0.4.19

- Give the Guition application task more stack space. A crash recovered from
  the owner's remote showed that tapping Load in Twin could exhaust the
  previous 8 KiB stack and restart the remote.
- Include up to 40 recent events in an approved Wi-Fi debug report. Reports
  also include the current boot's reset reason and, when available, the
  verified crash record's build fingerprint, exception code and instruction
  address. Larger approved reports can be saved for later delivery.
- On boot, save one small summary of a recognized crash, verify it, then
  clear the raw crash dump from the dedicated flash partition. The summary
  survives power cycles and is replaced by the next recognized crash.

Twin Load and Unload still use the current controller and existing readiness
checks. The crash fix has not been tested under physical resistance.

Unload the VOLTRAs and leave the connection. In **Settings → Updates** select
**Check for updates**, then **Install & Restart**. Keep power connected.
