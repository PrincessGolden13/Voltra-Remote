# VOLTRA Remote v0.4.8

- Add a cyan circular hold indicator after 300 ms, completing at two seconds.
  Release when full to request Auto Load; releasing early cancels the hold.
  Ordinary taps still Load/Unload immediately. Six-second debugging remains
  separate and cannot trigger Auto Load first.
- Make Auto Load prominent while starting/armed, with pull-and-hold guidance,
  tap-to-cancel and the actual VOLTRA countdown when available. No countdown is
  invented by the remote; resistance brightness follows device confirmation.
- Fix the unload-to-load transition shown in debug report 5a65d590 on v0.4.7.
  Read motor and Auto Load status together, and keep Unload pending until a
  direct device response confirms both motor 0 and Auto Load status 0.
- A tap or Auto Load hold while that reset is pending keeps the unloading
  message instead of opening a load-failure dialog. Wait for it to finish, then
  tap again to load or hold and release for Auto Load. No action is queued.
- Distinguish a completed Auto Load awaiting reset from an active Auto Load.
  Existing load readiness, cable, lock, mode, activation and link checks remain
  required. No Auto Load settings, force command or resistance retry is added.

For Guition K5 with the existing v0.4.1+ layout. Unload and leave Bluetooth,
then Settings -> Updates -> CHECK FOR UPDATES -> INSTALL & RESTART. Keep power
connected. Settings, saved Wi-Fi and the flash layout are unchanged.

Validation: public Normal and isolated Simulator builds, offline core, existing
protocol validators, image/manifest/USB consistency and linked backend isolation
pass. Real LVGL previews cover hold, Starting, armed, countdown, cancel and loaded
return at 360/466/480. Details are recorded in docs/TESTING.md. New visual behavior,
countdown compatibility and reset timing require the owner's physical check;
automated checks never engage a physical motor.
