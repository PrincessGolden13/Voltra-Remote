# VOLTRA Remote v0.4.8

- Fix the unload-to-load transition shown in debug report 5a65d590 on v0.4.7.
  Read motor and Auto Load status together, and keep Unload pending until a
  direct device response confirms both motor 0 and Auto Load status 0.
- A tap or Auto Load hold while that reset is pending keeps the unloading
  message instead of opening a load-failure dialog. Wait for it to finish, then
  tap again to load or hold and release for Auto Load. No action is queued.
- Distinguish a completed Auto Load awaiting reset from an active Auto Load.
  Existing load readiness, cable, lock, mode, activation and link checks remain
  required. No Auto Load settings, force command or resistance retry is added.

For Guition K5 with the existing v0.4.1+ layout. Unload and leave Bluetooth,
then Settings -> Updates -> CHECK FOR UPDATES -> INSTALL & RESTART. Keep power
connected. Settings, saved Wi-Fi and the flash layout are unchanged.

Build/package validation is recorded in docs/TESTING.md. Actual resistance
behavior and reset timing require the owner's physical check; automated checks
never engage a physical motor.
