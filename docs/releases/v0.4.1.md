Fixes GitHub update downloads on the Guition JC3636K518 remote.

- Accommodates GitHub's long signed download URLs in the HTTP request buffer.
- Resolves DNS before TLS, allows slower connections, and shares the radio between
  startup Wi-Fi and Bluetooth discovery.
- Keeps the power-on check and explicit INSTALL & RESTART prompt. Manual checks
  use the same published GitHub release feed.
- Adds firmware/slot and retained-profile startup diagnostics without secrets.

The owner's board has completed a verified USB layout migration and both
automatic power-on and manual HTTPS release checks. OTA installation/reboot and power-cut rollback are separate
physical checks; source/build validation alone does not establish them.

**Development preview:** fresh generated BLE identities have not established
pairing in earlier physical trials. Existing local profiles can be retained in
device NVS; public firmware contains no private profile. See README.md.

Older flash layouts require the USB bundle first. Do not install while training.
The OTA BIN is only the Normal application; never flash it at address zero.
The USB ZIP contains the initial installer and the relink ZIP contains objects
and ELF files for rebuilding with modified dependencies.
