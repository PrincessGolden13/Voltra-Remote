# VOLTRA Remote v0.4.29 — Faster standalone Live weight

- Read the VOLTRA's live weight more often during a standalone set when the
  device supports the fallback read. This lets the remote show more of the
  smaller whole-pound changes during a rep.
- Keep priority for the VOLTRA's streamed target and for control traffic.

Open **Settings → Updates**, then **Install & Update** when offered.
