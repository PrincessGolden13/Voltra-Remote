# VOLTRA Remote v0.4.16 — Connection setup compatibility

This update follows a fresh comparison of ten VOLTRA repositories and the
official-app capture after report1cb1cbf1 on v0.4.15.

- Discover and cache the characteristic table once per connection, avoiding the
  repeated full-service scans introduced by v0.4.15's individual lookups.
- Establish a supported response subscription before the opening message.
  Accept either documented response channel when available, with successful
  subscription and full VOLTRA authentication still required.
- Keep telemetry optional and preserve actual disconnect reasons when discovery
  fails, instead of hiding them behind a generic subscription message.

Existing Twin refresh, visible-member selection and resistance safeguards remain.
Source/build/offline checks do not prove physical connection recovery. No pairing,
role change or motor operation was performed during development.

Unload both VOLTRAs and leave the connection, then Settings -> Updates -> CHECK
FOR UPDATES -> INSTALL & RESTART. Keep power connected.
