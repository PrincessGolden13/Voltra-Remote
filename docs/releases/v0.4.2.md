# VOLTRA Remote v0.4.2

- Correct idle-time arithmetic that could cause immediate dim/sleep after an input.
- Keep useful Bluetooth failure explanations visible, and retain manual
  disconnection without automatic reconnection when tapping the device name.
- Add a six-second hold to approve sending the last 20 diagnostic events.
  Ordinary Auto Load/editor holds now execute on finger release before six seconds.
  Reports wait for Wi-Fi after leaving VOLTRA; approved queued reports survive reboot.
- Preserve valid preferences even when a preset is damaged, and protect unknown
  future settings schemas from older firmware overwrites. OTA preserves all NVS.
- Distinguish stale safety status from an unrecognized numeric value in errors
  and include relevant field values/ages in approved diagnostic reports.

Physical Twin control is still unsupported. The reported safety-state load
failure is instrumented, not established as fixed. The expanded source audit is
in docs/PROTOCOL_AUDIT_2026_11_09.md. No safety bypass or automatic load retries.

For the Guition K5 board only. Initial USB installation remains required for old
partition layouts. Existing v0.4.1 installations can use the normal prompted OTA
flow once this release is published. Do not install on other boards.

Release gate: diagnostic intake public-access approval and deployed delivery
verification must be complete before publishing this release.
