# VOLTRA Remote v0.4.4

- Add Settings -> Send debug log alongside the six-second hold. Both ask for
  consent before submitting the last 20 events over saved Wi-Fi.
- Disable touch-controller reset timers that can interrupt long holds; add a
  visible hold countdown and allow ordinary finger drift for the debug gesture.
- Show load refusals in a readable notice with Send debug log and Unload.
  Preserve the failure's numeric state after leaving the VOLTRA connection.
- Separate optional protocol reads from required load-state polls. Identify
  the reason for a refused load more precisely, without weakening safety checks.
- Require a fresh direct motor read for loaded writes; prevent a documented
  stale settings echo from authorizing the wrong write path. Log actual weight
  writes, readbacks and force context for dropset diagnosis.

The reported active-set RP resistance-change failure and White's exact load
refusal are not established as resolved. Active motor mode 5 still cannot use
automatic weight edits; no automatic reload or safety bypass was added. Twin
control remains unsupported. See docs/BUG_FIXES_2026_11_14.md for evidence.

For Guition K5, existing v0.4.1+ layout only. OTA preserves settings and Wi-Fi.
With VOLTRAs unloaded, leave the Bluetooth connection and choose Settings ->
Updates -> CHECK FOR UPDATES -> INSTALL & RESTART. Installation is an explicit
owner action. Physical behavior of this version remains to be verified.
