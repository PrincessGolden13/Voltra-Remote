# VOLTRA Remote v0.4.21

- Twin Auto Load now opens Live as soon as the controller confirms the load.
  The calibration rep and a reported armed phase during that handoff keep
  Live open. A confirmed unload returns to Adjust.
- Send debug log now shows when Wi-Fi is disconnected. **Retry Wi-Fi** uses
  the saved network without restarting the remote. The report remains saved
  until delivery.

The recovered Twin Live flow still needs a physical check. Load and unload
commands and the machine readiness checks are unchanged.

Unload the VOLTRAs and leave the connection. In **Settings → Updates**,
choose **Check for updates**, then **Install & Restart**. Keep power connected.
