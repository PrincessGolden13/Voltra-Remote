# VOLTRA Remote v0.4.18 — Stairs timing and Auto Load

- Correct Stairs' use of the return-start notification. Wait for a fresh,
  stationary return-to-idle observation before changing weight.
- Cancel an unsent automatic weight change if movement resumes or its valid
  window passes. Keep confirmation of changes already sent.
- Include the Auto Load fixes: prompt activation checks, immediate Live after
  confirmed single-unit loading, and the reference stream-refresh sequence.
- Remove the waiting message during ordinary weight dial changes.

v0.4.17 was held unpublished after the Stairs report; this update includes it.
Live still uses only the VOLTRA's reported weight. Physical Auto Load feed
recovery and Stairs timing remain unverified. If no valid stationary endpoint
is reported, the remote must wait or stop the drop rather than change midrep.

Unload the VOLTRAs and leave the connection, then Settings -> Updates -> CHECK
FOR UPDATES -> INSTALL & RESTART. Keep power connected.
