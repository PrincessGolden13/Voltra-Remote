# VOLTRA Remote v0.4.25 — Twin Drops and BLE trace

- Leave either Drops editor with **Back**. In Twin, **Save** keeps the recipe
  locally without arming automatic drops.
- The selected RP control has a distinct outline and matching label and value.
- An unavailable remote Auto Load action no longer claims the VOLTRA setting
  is off. The trigger still requires confirmed device readiness.
- **Settings → BLE trace** records a bounded sample of training telemetry.
  Enable it before a Twin set. Choose **Settings → Send log → SEND**
  afterward to include the trace, then switch it off.

The combined Live weight still needs a verified Twin field. Single VOLTRA
Live weight continues to use the device-reported target.

Unload the VOLTRAs and leave the connection. In **Settings → Updates**,
choose **Check for updates**, then **Install & Restart**. Keep power connected.
