# VOLTRA Remote v0.4.10 — Twin diagnostics

This diagnostic update improves Twin status decoding and captures detail missing
from report357833b6. **Twin weight adjustment, load and unload remain unavailable.**
An unresolved master stops the connection check and offers Send debug log.
This is not a completed Twin-control fix.

- Retain full identity when battery metadata is unavailable or state is
  transitional. Unknown state stays unknown; paired totals still require
  confirmed, identity-matched paired status.
- Record sanitized rejection/header and address-slot match details without
  addresses or names. Bound repeated failures so they do not flood the event log.

- Treat the overlapping Twin circles as one selection, with one availability
  state for both members. Resolve the current master before opening training;
  names, colors, scan order and the first observed endpoint never decide its role.
- Remember that pair for navigation across restarts, without restoring live
  connection, readiness or load state.
- Keep the training header to the paired VOLTRA names. Remove the redundant
  Twin caption, TOTAL LB heading, dial-overlapping glyph and technical banner.
- Honor the two-pound combined-LB adjustment step where the pair's setting
  scope is known, including supported simulator editing paths.
- Correct Live's data source to VOLTRA's separate reported target resistance.
  The previous runtime-weight register can be cable tension. Missing/stale or
  unsupported targets show --; no tension, base or percentage fallback is used.
- Warn at 10% or below on the remote's battery estimate. Defer while Live or a
  known active set is in progress, then show once on an idle screen. Keep UNLOAD
  available; acknowledge with OK. Battery level uses the K518 voltage profile,
  with missing/invalid/USB-range readings unavailable. Physical calibration is
  still unverified.

This release corrects presentation and provides read-only connection diagnostics.
Physical Twin control remains unavailable pending current master, both units'
safety and combined-limit evidence; the dial blocker is not claimed fixed.
Use the VOLTRAs' own controls for the pair. Maximum resistance is not inferred
by doubling a single-unit report.

Unload both VOLTRAs and leave Bluetooth, then Settings -> Updates -> CHECK FOR
UPDATES -> INSTALL & RESTART. Keep power connected. After updating, select the
pair and let the check finish. If it cannot identify the master, choose Send debug
log, then SEND. The new report contains fields that v0.4.9 could not capture;
no repeated description or report code is needed.
