# VOLTRA Remote v0.4.23 — Twin handoff and Live

- When a connected VOLTRA joins Twin, keep the current controller connection
  or find the verified controller automatically once the follower is idle.
- Show Auto Load progress when available and give feedback during the hold
  if the controller reports it unavailable.
- Open Live after a confirmed direct Twin load. Request the controller's
  stream promptly and show its set and rep counts as they arrive.

Physical handoff and telemetry recovery still need verification. The remote
uses reported data and does not estimate Twin target resistance.

Unload the VOLTRAs and leave the connection. In **Settings → Updates**,
choose **Check for updates**, then **Install & Restart**. Keep power connected.
