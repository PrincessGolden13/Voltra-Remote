# VOLTRA Remote v0.4.14 — Wi-Fi and Bluetooth handoff

Pause Wi-Fi before starting a queued VOLTRA Bluetooth connection. Previously,
selecting a device, Retry or automatic connection could start Bluetooth before
the remote requested Wi-Fi shutdown. Refresh the application clock after that
shutdown, and preserve immediate Wi-Fi recovery for debug reports and updates
once the VOLTRA connection has ended.

The latest v0.4.13 report shows the primary timing out before discovery or
authentication. Offline checks confirm this ordering defect and its correction;
they do not establish that it caused that timeout or prove physical recovery.
The existing Twin controls, connection limits and retry policy are unchanged.
Saved Wi-Fi and preferences are preserved.

Unload both VOLTRAs and leave the connection, then Settings -> Updates -> CHECK
FOR UPDATES -> INSTALL & RESTART. Keep power connected.
