# VOLTRA Remote v0.4.28 — Auto Load guidance and Live weight

- Show larger Auto Load instructions after releasing the hold. Follow
  Pull & Stabilize, the reported countdown and Progressive Loading, with
  Cancel available.
- Keep a real Live weight reading visible through short Bluetooth gaps
  during the same loaded workout.
- Add **Adjust while loaded** in Settings, on by default. It controls
  the manual dial while the VOLTRA is loaded.

Open **Settings → Updates**, then **Install & Update** when offered.
