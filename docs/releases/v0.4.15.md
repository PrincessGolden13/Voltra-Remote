# VOLTRA Remote v0.4.15 — Twin discovery and connection setup

- Refresh Twin grouping from current VOLTRA status while the device screen is
  idle. Joining, leaving or changing a pair updates the overlapping icons.
- Start with a currently visible member of a remembered pair, avoiding a wait
  on an absent member first. Keep the icons visible during background refresh;
  use one short Connecting message for an explicit connection.
- Send the opening protocol message before notification setup, matching the
  native reference's timing. Continue scanning after connection failures.
- Keep unrelated Bluetooth advertisers from filling the VOLTRA discovery list.

Background checks are read-only and yield to selection, settings, debug reports
and updates. Existing load/unload safeguards and fresh control-role checks apply.
The latest error 531 means the VOLTRA ended an established Bluetooth link;
offline checks do not prove the cause or physical recovery. The official app's
current route through Red is not assumed to be a secondary relay.

Saved Wi-Fi and preferences are preserved. Unload both VOLTRAs and leave the
connection, then Settings -> Updates -> CHECK FOR UPDATES -> INSTALL & RESTART.
Keep power connected.
