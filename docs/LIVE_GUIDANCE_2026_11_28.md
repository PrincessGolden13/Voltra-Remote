# Auto Load, Live weight, and the loaded dial

## Auto Load video

The native VOLTRA clip first shows **Pull & Stabilize** and tells the user to
pull the cable to the start position and stay steady. The countdown remains
on that stage. **Progressive Loading** then tells the user to move through
the first rep. Cancel remains visible. The remote clip shows the hold ring
working, followed by small cable and engaging instructions.

The remote keeps its existing hold gesture. After release it shows prominent
instructions and a Cancel action. Guidance follows the machine's reported
stages and countdown. The VOLTRA still owns all safety and ramp timing.

## Live weight video

The native clip shows continuous whole-pound readings throughout the reps,
including values from about 59 to 89 lb. In the separate remote clip, White
has a selected base of 55 lb and reports live readings including 58, 60, 68,
84 and 87 lb. The remote alternates between readings and dashes while rep
counters continue. These are separate sets and cannot establish sample-by-sample
agreement between displays.

The previous display expired a reading after 500 ms. The isolated motor
readback shares a paced Bluetooth link with core state, topology and control
work. The standalone Live readout now keeps the last device target for up to
1.5 seconds while fresh reports confirm the same loaded rep phase. Each fresh
target appears immediately, with fresh B4 targets retaining priority. Changes
of selected weight, unit, load session or device invalidate a cached reading.
The display shows received target values in the chosen units. This evidence
does not establish a valid Live target for Twin mode.

## Loaded weight adjustment

The remote clip shows **Unload to adjust** on White through the active set
and on returning to the weight screen. It cannot establish the current
direct motor or lock readbacks. **Adjust while loaded** is a saved
remote setting. It defaults on and gates manual dial changes while loaded.
Device readiness still determines whether a request can be sent. An eligible
loaded dial change writes only base weight and preserves the machine's exact
accessory settings. The standalone active motor state that requires a second
motor operation after an edit stays gated. Automatic Stairs and RP use their
existing execution capabilities. The standalone White and Twin device paths
remain physical checks.
